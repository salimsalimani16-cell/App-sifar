# SIFAR Technologies -- Dossier de projet

## Vision

Créer une entreprise technologique spécialisée dans les solutions NFC,
RFID, contrôle d'accès et logiciels pour hôtels, restaurants et
entreprises.

## Marques

-   SIFAR Smart NFC
-   SIFAR Smart Access
-   SIFAR Smart Hotel
-   SIFAR Smart Trace
-   SIFAR AI
-   SIFAR Cloud

## Objectifs

-   Site web professionnel
-   Plateforme SaaS
-   Applications Flutter (Android/iOS/Windows/Web)
-   Backend NestJS + PostgreSQL
-   Tableau de bord
-   Encodage NFC
